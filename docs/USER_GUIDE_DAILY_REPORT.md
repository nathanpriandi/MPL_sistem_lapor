# Panduan Pengisian Laporan Operasional Harian (Daily Report)

Panduan ini ditujukan untuk **Staf Lapangan / Mandor Kebun / Pengawas Peternakan & Pabrik** dalam mengoperasikan sistem pelaporan digital harian.

---

## 📱 Cara Mengakses Formulir

1. Buka browser (Chrome / Safari / Browser HP) di ponsel Anda.
2. Buka link **Web App Sistem Pelaporan Digital** (atau pindai / scan QR Code yang terpasang di papan pengumuman lokasi kerja).
3. **Tidak memerlukan login / email** Google Account.
4. *(Opsional)* Jika jaringan internet lambat atau terjadi kendala pada Web App, Anda dapat menggunakan link cadangan **Google Form Harian**.

---

## 📝 Langkah-Langkah Pengisian (Kurang dari 2 Menit)

### Langkah 1: Kode Karyawan / Employee ID
- Masukkan kode unik karyawan Anda (contoh: `EMP-101`, `KAB-05`).

### Langkah 2: Lokasi / Site
- Pilih lokasi kerja Anda hari ini dari daftar drop-down:
  - **Site A — Kebun & Lahan Pertanian**
  - **Site B — Peternakan & Kandang**
  - **Site C — Pabrik Pengolahan & Pakan**
  - **Site D — Logistik & Gudang**

### Langkah 3: Tanggal Laporan
- Masukkan tanggal hari ini.

### Langkah 4: Status Tugas
- Pilih kondisi ketercapaian target hari ini:
  - **Completed** (Selesai sesuai target)
  - **In Progress** (Sedang berjalan)
  - **Delayed** (Tertunda / Mengalami hambatan)

### Langkah 5: Hasil Panen / Produksi (Kg)
- Isi total kilogram (kg) hasil panen atau output produksi harian (contoh: `1250`). Jika tidak ada panen hari ini, kosongkan atau isi `0`.

### Langkah 6: Ada Masalah? (Issues)
- Centang kendala utama yang dialami (bisa memilih lebih dari satu):
  - `Equipment` (Mesin / Alat rusak)
  - `Weather` (Hujan deras / Becek / Cuaca ekstrem)
  - `Shortage` (Kekurangan pupuk / pakan / bahan / pekerja)
  - `None` (Lancar tanpa kendala)

---

## 📩 Pengiriman
- Tekan tombol **Kirim / Submit**.
- Pengisian laporan Anda telah selesai. Data otomatis tercatat di sistem central.

---

## 📷 Foto Bukti / Lampiran (Jika Ada)
- Karena formulir didesain tanpa memerlukan login Google, foto lampiran dikirimkan terpisah melalui WhatsApp Operasional Admin dengan menyebutkan **Kode Karyawan** & **Lokasi Site**.
