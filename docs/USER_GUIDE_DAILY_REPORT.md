# Panduan Pengisian Laporan Operasional (Kegiatan, Panen & Penjualan)

Panduan ini ditujukan untuk **Staf Lapangan / Mandor Kebun / Pengawas Peternakan & Perikanan** dalam mengisi formulir pelaporan operasional digital.

---

## 📱 Cara Mengakses Formulir

1. Buka browser (Chrome / Safari / Browser HP) di ponsel Anda.
2. Buka link **Web App Sistem Pelaporan Digital Operasional**.
3. **Tidak memerlukan login / email Google Account**.
4. *(Opsional)* Jika jaringan internet lambat, Anda dapat menggunakan link cadangan **Google Form Native**.

---

## 📝 Langkah-Langkah Pengisian Formulir (Single-Pass Submission)

### Bagian 1: Detail Kegiatan Operasional (Wajib)
1. **Nama PIC Lokasi**: Masukkan nama pelapor / penanggung jawab lokasi.
2. **Bidang / Divisi**: Pilih salah satu (`Agro`, `Ternak`, atau `Ikan`).
   - Jika **Agro**: Isi **Jadwal / Tanggal Tanam** (Wajib).
   - Jika **Ternak / Ikan**: Isi **Jadwal / Tanggal Check-in / Tebar** (Wajib).
3. **Lokasi Kegiatan**: Masukkan nama blok kebun / kandang / kolam.
4. **Jenis Kegiatan**: Contoh: Penanaman, Pemupukan, Pemberian Pakan, Panen.
5. **Target Kegiatan**: Rincikan target aktivitas hari ini.
6. **Luas Area (Ha) / Jumlah Populasi**: Isi angka estimasi (jika ada).
7. **Jadwal / Perkiraan Tanggal Panen**: Isi tanggal estimasi panen.

### Bagian 2: Data Panen & Penjualan (Opsional)
> *Isi bagian ini jika pada hari pelaporan terdapat hasil panen atau transaksi penjualan.*

1. **Kode Kegiatan Referensi**: Digunakan jika laporan ini merupakan lanjutan dari kegiatan sebelumnya (masukkan kode reference seperti `AGR-KEBUNA-20260807-01`).
2. **Tanggal Panen & Jumlah Panen (Kg/Unit)**: Isi jika melakukan panen hari ini.
3. **Tanggal Penjualan, Harga Jual, & Nilai Penjualan Total (Rp)**: Isi jika ada hasil penjualan.

### Bagian 3: Kendala, Upaya & Bukti Foto
1. **Kendala Kegiatan**: Isi jika ada hambatan (Opsional).
2. **Upaya Yang Dilakukan**: Isi solusi/tindakan yang telah diambil (Opsional).
3. **Foto Bukti Kegiatan (3 Foto Wajib Dilampirkan)**:
   - Lampirkan 3 foto bukti dokumentasi: **Foto 1 (Utama)**, **Foto 2 (Detail Aktivitas)**, dan **Foto 3 (Hasil / Kondisi Area)**.
   - Di ponsel pintar (HP), tekan tombol foto untuk langsung **mengambil foto dengan kamera HP** secara otomatis.
   - Di peramban komputer/laptop, pilih file foto dokumentasi dari komputer Anda.
   - Sistem akan otomatis mengompresi foto dan membubuhkan stempel verifikasi (watermark tanggal, waktu, nama pelapor, dan lokasi).

---

## 🔑 Konfirmasi & Kode Kegiatan Auto-Generated

Setelah menekan tombol **Kirim Laporan Operasional**, layar konfirmasi akan menampilkan **Kode Kegiatan** unik Anda (contoh: `AGR-KEBUNA-20260807-12`).
- Tekan tombol **Salin Kode** untuk menyimpan kode tersebut jika diperlukan untuk laporan panen lanjutan di kemudian hari.
